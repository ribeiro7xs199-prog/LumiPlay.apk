      Adicionar filme ou série

      Pesquise o nome no TMDB e escolha o resultado correto. Os dados são preenchidos automaticamente; depois, em Editar, basta colar a URL direta do vídeo, se você tiver uma.

      Digite o nome para começar.

      Dados do título

      A legenda deve ser um arquivo .vtt servido por HTTPS com acesso liberado ao navegador (CORS). Para salvar este campo no banco, execute database/supabase-player-enhancements.sql.

      Temporadas e episódios

      Use “Buscar nome, descrição e ID no TMDB” para preencher automaticamente (conecte o TMDB pelo menu do perfil e informe o ID correto da série).

      Dados técnicos (JSON, avançado)

      O player usa o ID TMDB da série + número da temporada + número do episódio. O ID individual do episódio é guardado apenas como metadado.

      Importação automática

      TMDB → Supabase

      Importa até 1.000 filmes e séries populares ou bem avaliados, em lotes. Não adiciona vídeos e não sobrescreve registros existentes.

      Pronto para importar. É necessário estar conectado ao TMDB e como administrador.

      Títulos cadastrados

      Catálogo online (TMDB)

      O TMDB já está configurado neste site e os títulos populares carregam automaticamente. Use este campo só para substituir a chave padrão.

      A chave padrão faz parte do código publicado e fica visível aos visitantes. Use somente uma chave pública de API; nunca cole senhas ou chaves privadas.
